## Projeto em destaque: WERT

O WERT e um projeto em que atuei na construcao de uma aplicacao web com frontend, backend, banco de dados e deploy.

No frontend, trabalhei com Next.js, React, TypeScript, Tailwind CSS e fluxo de autenticacao. No backend, a base utiliza Node.js, Express, TypeScript, Prisma e PostgreSQL, com organizacao de rotas, regras de acesso e CRUDs para entidades do sistema.

Tambem participei da parte de infraestrutura, colocando a aplicacao em ambiente AWS com EC2/RDS, Nginx, PM2, SSL com Let's Encrypt e deploy em producao.
